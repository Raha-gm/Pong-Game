# Pong Game 🏓

A classic two-player Pong game built with Python and Turtle graphics.

Players control paddles to hit the ball and compete to score points.

## Features

- Two-player gameplay
- Keyboard paddle controls
- Ball movement and collision detection
- Score tracking
- Custom GIF graphics
- Sound effects

## Technologies Used

- Python
- Turtle Graphics
- Object-Oriented Programming
- Winsound

## Controls

| Player | Move Up | Move Down |
|---|---|---|
| Right Player | Up Arrow | Down Arrow |
| Left Player | W | S |

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Keep all game assets in the same folder as the Python files.
4. Run:

```bash
python main.py
```

## Requirements

- Python
- Turtle module
- Winsound (Windows only)

## Note

The sound effects use the Windows-specific `winsound` module.
